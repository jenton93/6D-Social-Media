# Website Copy

**Everything here is written, including the parts that had to be assumed.**

Copy has been the blocker on this build since January. The reason isn't
reluctance — it's that writing from a blank page needs a long uninterrupted
sitting from the person with the least time in the business. A template with
blanks in it would sit for another eight months.

So nothing here is blank.

| Marker | Meaning | What to do |
|---|---|---|
| `‹ASSUMED›` | I've written what's most likely true from the brief | Read it. If it's wrong, change it. If it's right, delete the marker |
| ⛔ | A hard fact I can't invent — company number, insurance figure, a name | Look it up and paste it in. Thirty seconds each |

**Correcting is quick. Composing is what never happens.** Read these as
someone else's draft you're marking up, not as homework.

## Order to work through

1. `home.md` — the page that does most of the work
2. `services.md` — overview plus all six departments
3. `about.md` — the one that needs the most from you
4. `contact.md`, `credentials.md` — mostly facts

## Before any of it goes to Will

Read each page **out loud**. That's the real test in
`strategy/01-voice-and-tone.md` §6 — it catches the sentences that read fine
silently and sound like a brochure when spoken. Anything you wouldn't say to a
producer in the van, change.
