# Placeholder imagery

**These are not photographs and they must never reach the live site.**

Generated abstract blocks, used in `content/website/export/6D-design-direction.html`
so the layout could be judged with something in the frame instead of empty
boxes. Each one is marked "Placeholder" in the corner where it's used.

They're deliberately abstract rather than stock. Stock would carry a licence,
it breaks rule 8 in `CLAUDE.md`, and it would make the mockup look better than
the site can actually launch, which is the wrong footing for a design decision.

Delete this folder once the real shot list in `strategy/13-design-direction.md`
§5 is filled.
