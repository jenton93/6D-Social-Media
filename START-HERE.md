# Christian — start here

This repo is the content and website plan. Claude reads `CLAUDE.md`
automatically every time, so it already knows the business, the positioning
and the rules. You don't need to explain any of it.

## Getting in

1. GitHub access to this repository — Jenton can add you
2. Go to **claude.ai/code**, pick the repository, and start a session
3. Branch: `claude/social-blog-content-strategy-yimpq5`

> **Note:** the repositories are moving from Jenton's personal GitHub account
> to a 6D Group organisation. If Claude can't see the repo after that, it's
> almost certainly the org-access step below rather than anything broken.

## The single most useful thing you can do

**Talk, don't write.** Record 60–90 seconds on your phone about something from
the week, paste the transcript in, and ask for it to be turned into a post.

That's how the first blog post was made. Four minutes of Jenton talking
produced a 780-word article, four social posts, website copy for three pages,
and four more posts queued up. Nobody sat down to write anything.

Prompts to pick from, if you want them:
`templates/director-voice-note-brief.md`

The transcript doesn't need tidying. Tangents, hesitations and *"actually, no,
the real reason was…"* are the parts that make it sound like you — those get
kept.

## Things worth asking it to do

- *"Turn this voice note into a LinkedIn post"*
- *"Read me the blog post"* — it'll print the whole thing
- *"What's still blocking the website?"* — it'll tell you exactly
- *"Write the case study"* — give it delegates, rooms, get-in hours, crew, and
  the thing that was difficult
- *"I disagree with this because…"* — genuinely useful. Several of the best
  decisions in here came from Jenton pushing back, and it changes the plan and
  writes down why

## If Claude can't see the repository

After the move to an organisation, GitHub access has to be granted at the
**org** level — being a member isn't enough on its own. An org owner does it
once:

- **claude.ai → Settings → Connectors → GitHub**, and authorise the 6D Group
  organisation
- Then each person picks the repo from its new location in claude.ai/code

Old links keep redirecting, but a session started against the old path may
lose access. Easiest fix is to start a fresh session and pick the repo again.

## Two things to know

**It will get things wrong about the business.** It only knows what it's been
told. Correcting it is the fastest way to improve the whole plan — every
correction gets written into `strategy/` and applies from then on.

**Everything it writes needs reading aloud before it goes out.** That's the
actual test. If you wouldn't say it to a producer in the van, change it — that
instinct is more reliable than any style guide.
